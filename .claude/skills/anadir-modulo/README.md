Esta carpeta es la **segunda** entrevista: una web que ya existe y quiere una sección más.
Se invoca con `/anadir-modulo` desde este repositorio.

La primera vive en [`nuevo-sitio`](../nuevo-sitio) y pregunta quince cosas. Ésta pregunta
tres, porque la identidad, la paleta y lo legal ya están escritos en el `sitewright.json` de
esa web.

El fichero que importa es `SKILL.md`. Si cambias el esquema del blueprint o añades un
módulo, actualízalo: una entrevista que pregunta por algo que ya no existe es peor que
ninguna.
